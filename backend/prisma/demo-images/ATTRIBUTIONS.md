# Images du catalogue de démonstration

Photos **réservées aux données de démonstration du développement** (`SEED_DEMO=true`), associées aux plats de démo
qu’elles représentent. Elles proviennent de Wikimedia Commons ; licence et auteur ont été vérifiés via l’API de
Commons le 2026-10-18. Chaque image a été adaptée (voir colonne « Modification ») ; une image adaptée d’une œuvre
CC BY-SA reste sous la même licence.

Ne pas utiliser ces images pour de vrais restaurants : en production, chaque restaurant publie les photos de ses propres plats.
